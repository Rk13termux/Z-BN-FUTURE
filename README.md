# Z-BN-FUTURE

Binance Futures Trading Bot - Electron Desktop Application

## Features
- Real-time cryptocurrency price charts
- Technical indicators (RSI, MACD, EMA, Bollinger Bands, Stochastic, etc.)
- Trading signals analysis
- Volatility analysis
- Market structure analysis
- Order book visualization
- Sentiment data integration

## Installation

```bash
npm install
npm start
```

## Tech Stack
- Electron
- Chart.js
- Binance API
- Technical Indicators
